# Rotinas

As tarefas agendadas ficam no aplicativo do Claude, fora do repositório: trocando de computador, elas somem. Aqui fica uma cópia do que cada uma faz, pra recriar em minutos. Nada de cliente nestes arquivos: tudo que muda vem de `vendas/ESTADO.md` e do funil na hora de rodar.

| Rotina | Quando | Arquivo |
|---|---|---|
| Lote diário de prospecção | Segunda a sexta, 9h | `lote-diario.md` |
| Vigia semanal | Segunda, 8h30 | `vigia-semanal.md` |

## Recriar

No Claude Code, pedir "cria a tarefa agendada de `rotinas/<arquivo>`", com o horário da tabela. Mudou uma rotina no app? Atualizar o arquivo aqui também.

Tarefas de uma vez só (como follow-up de um dia específico) não entram aqui: elas têm nome de loja e terminam sozinhas.
